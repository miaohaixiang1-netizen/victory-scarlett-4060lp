Local 4060 laptop reference files. These snapshots contain machine-specific paths and require adjustment before use elsewhere. Game data, saves, logs, caches, and binaries are not included. The session monitor logs GPU and available RAM every 30 seconds and exits with the game. GPU timestamp reporting needs the diagnostics build and VICTORY_CARD_SPANS=1. Current paired-wave and VRAM-reservation settings are experimental; scene comparisons did not establish a 30 fps result or long-session stability.
